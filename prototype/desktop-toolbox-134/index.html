這三個頁面點進去是在做什麼？

⌂

1. Home / Dashboard

桌面工具的總入口。顯示最近專案、模組狀態、HyperMesh/Python 連線狀態與下一步。

  • 快速進入常用工具
  • 保留最近處理的專案
  • 之後統合所有 Desktop 模組
⇄

3. Model Converter

把 HyperMesh / OptiStruct 模型轉為可分析的 LS-DYNA 模型，並逐項追蹤 Material、Property、Contact、Connector 與 ELFORM。

  • 選模型與轉換規則
  • 顯示修復項目與 log
  • 先做 Dry Run，再接真正 HM API
◇

4. Density Tuner

沿用你既有 Material Library 的公式，以目前重量、目標重量與數量計算建議密度。

  • 支援 ton / kg / g
  • 即時計算 Recommended Density
  • Desktop 後續可直接套用 HyperMesh
